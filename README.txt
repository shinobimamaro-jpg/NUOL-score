NUOL Scores + XAMPP (Apache + PHP + MySQL)
==========================================

1) เปิด XAMPP Control Panel แล้วกด Start ที่ Apache และ MySQL
2) คัดลอกโฟลเดอร์ nuol_scores ทั้งโฟลเดอร์ไปไว้ที่  C:\xampp\htdocs\
3) เปิด http://localhost/phpmyadmin  ->  แท็บ Import  ->  เลือกไฟล์ database.sql  ->  Go
   (สร้างฐานข้อมูล nuol_scores 13 ตาราง พร้อมข้อมูลตัวอย่าง 40 นักเรียน)
4) เปิด http://localhost/nuol_scores/

บัญชีทดลอง
  admin    : admin1234   / admin1234
  นักศึกษา : 2210001234  / student123

เช็กว่าเชื่อมต่อแล้ว: แถบด้านบนของเว็บจะขึ้น "● MySQL connected"
ถ้าขึ้น "○ Demo mode" แปลว่าเชื่อมไม่ได้ (เว็บยังใช้ได้ แต่เก็บข้อมูลในเบราว์เซอร์แทน)

ถ้า MySQL ของคุณมีรหัสผ่านหรือใช้พอร์ตอื่น ให้แก้ไฟล์ api/config.php
ถ้าแก้ database.sql แล้วนำเข้าใหม่ ข้อมูลเดิมจะถูกล้างและกลับเป็นข้อมูลตัวอย่าง

ที่เชื่อมกับ MySQL แล้ว: ล็อกอิน/สมัคร/ออกจากระบบ, รายชื่อนักเรียน (เพิ่ม แก้ไข ลบ),
ประเภทการเรียน, เครดิตรายเดือน, เปลี่ยนรหัสผ่าน (เก็บแบบ bcrypt)
ที่ยังใช้ข้อมูลในหน้าเว็บ: ตารางเรียน, ข่าว, หน้า Account settings (โปรไฟล์) ส่วนตาราง
courses / semesters / course_offerings / enrollments / class_schedule สร้างไว้ใน DB พร้อมต่อยอดแล้ว

ความปลอดภัย: ชุดนี้สำหรับเครื่องของคุณ/เดโม ก่อนใช้งานจริงให้เปลี่ยนรหัส admin1234 และตั้งรหัสผ่าน MySQL
