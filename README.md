# NUOL Scores (ระบบจัดการคะแนนและข้อมูลนักศึกษา)

ระบบเว็บแอปพลิเคชันสำหรับจัดการข้อมูลนักศึกษา คะแนน และเครดิตรายเดือน พัฒนาด้วย **HTML/JS (Frontend SPA)** และ **PHP + MySQL (Backend REST API)**

---

## 🚀 วิธีติดตั้งและใช้งานร่วมกับ XAMPP

1. **เปิด XAMPP Control Panel** และกด **Start** ที่โมดูล **Apache** และ **MySQL**
2. **คัดลอกโฟลเดอร์โปรเจกต์** ไปไว้ที่ C:\xampp\htdocs\nuol_scores
3. **นำเข้าฐานข้อมูล (Import Database)**
   * เปิดเบราว์เซอร์ไปที่ [http://localhost/phpmyadmin](http://localhost/phpmyadmin)
   * ไปที่แท็บ **Import**
   * เลือกไฟล์ database.sql แล้วกดปุ่ม **Import** (หรือ **Go**)
   * *(ระบบจะสร้างฐานข้อมูล 
uol_scores 13 ตาราง พร้อมข้อมูลตัวอย่างนักศึกษา 40 คน)*
4. **เปิดใช้งานระบบ**
   * เข้าใช้งานผ่านเบราว์เซอร์ที่: [http://localhost/nuol_scores/](http://localhost/nuol_scores/)

หาก MySQL ของคุณมีการตั้งรหัสผ่านหรือใช้พอร์ตอื่นที่ไม่ใช่ค่าเริ่มต้น (3306) สามารถแก้ไขได้ที่ไฟล์:

`

## 📁 โครงสร้างโปรเจกต์

* index.html — ส่วนติดต่อผู้ใช้ (Frontend Responsive SPA พร้อม Dark Theme)
* pi/index.php — API จัดการการล็อกอิน สมัครสมาชิก และข้อมูลนักเรียน
* pi/config.php — ไฟล์ตั้งค่าการเชื่อมต่อฐานข้อมูล
* pi/.htaccess — ป้องกันการเข้าถึงไฟล์คอนฟิกจากภายนอกโดยตรง
* database.sql — สคริปต์สร้างฐานข้อมูลและข้อมูลตัวอย่างเริ่มต้น
